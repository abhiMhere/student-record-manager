# Student Record Manager

A Flask and SQLite application for creating, searching, updating, and deleting student records.

## Run locally

```powershell
pip install -r requirements.txt
python sms.py
```

Open <http://127.0.0.1:5000> in your browser.

## Deploy

[Open the live app](https://student-record-manager-xcfj.onrender.com)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/abhiMhere/student-record-manager)

The deployment button creates a Render web service using `render.yaml`. The free service uses local SQLite storage, which is suitable for a demo but may be cleared when the service restarts or is redeployed.
